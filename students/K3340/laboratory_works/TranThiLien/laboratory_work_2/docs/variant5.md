# Вариант 5 — Список научных конференций

## Постановка задачи

Необходимо реализовать сайт с интерфейсом, описывающим:

- названия конференций;
- список тематик;
- место проведения;
- период проведения;
- описание конференций;
- описание места проведения;
- условия участия.

## Требуемый функционал

1. Регистрация новых пользователей.
2. Просмотр конференций и регистрация авторов для выступлений.
3. Возможность редактирования и удаления своих регистраций.
4. Написание отзывов к конференциям (дата, текст, рейтинг 1–10, автор).
5. Указание администратором результатов выступления (рекомендован к публикации или нет) средствами Django-admin.
6. Таблица участников по конференциям в клиентской части.

---

## 1. Модель данных

### 1.1 Conference

| Поле | Тип | Описание |
|------|-----|----------|
| `title` | CharField(200) | Название конференции |
| `topics` | M2M(Topic, through=ConferenceTopic) | Список тематик |
| `venue` | CharField(200) | Место проведения |
| `venue_ref` | FK(Venue) | Ссылка на модель места |
| `start_date` | DateField | Дата начала |
| `end_date` | DateField | Дата окончания |
| `description` | TextField | Описание конференции |
| `venue_desc` | TextField | Описание места |
| `conditions` | TextField | Условия участия |

### 1.2 Registration (Заявка на выступление)

| Поле | Тип | Описание |
|------|-----|----------|
| `conference` | FK(Conference) | Конференция |
| `author` | FK(User) | Автор заявки |
| `report_title` | CharField(300) | Название доклада |
| `abstract` | TextField | Аннотация |
| `status` | choices | pending / approved / rejected |
| `recommended` | BooleanField | Рекомендован к публикации |
| `created_at` | DateTimeField | Дата регистрации |

### 1.3 Review (Отзыв)

| Поле | Тип | Описание |
|------|-----|----------|
| `conference` | FK(Conference) | Конференция |
| `author` | FK(User) | Автор отзыва |
| `text` | TextField | Текст отзыва |
| `rating` | PositiveSmallIntegerField | Оценка 1–10 |
| `created_at` | DateTimeField | Дата отзыва |

## 3. Реализованные интерфейсы

### 3.1 Главная страница `/`

Отображает список всех конференций с:

- названием;
- периодом;
- местом;
- списком тематик (badges);
- кратким описанием;
- счётчиком заявок и отзывов.

### 3.2 Страница конференции `/conference/<id>/`

- полная информация о конференции (все 7 полей);
- список заявок с кнопками редактирования/удаления (только для своих);
- список отзывов с рейтингами;
- кнопки «Подать заявку» и «Оставить отзыв».

### 3.3 Подача заявки `/conference/<id>/register/`

Форма с полями «Название доклада» и «Аннотация».

### 3.4 Редактирование заявки `/registration/<id>/update/`

Пользователь может редактировать **только свои** заявки (защита через `get_queryset`).

### 3.5 Удаление заявки `/registration/<id>/delete/`

Страница подтверждения удаления.

### 3.6 Написание отзыва `/conference/<id>/review/`

Форма с полями «Текст отзыва» и «Оценка (1–10)».

### 3.7 Таблица участников `/participants/`

Сводная таблица по всем конференциям:

| # | Автор | Доклад | Статус | Рекомендован | Дата |
|---|-------|--------|--------|--------------|------|

### 3.8 Регистрация `/register/`

Форма создания нового пользователя с автоматическим входом.

### 3.9 Вход `/accounts/login/`

Стандартная форма аутентификации Django.

## 4. Admin actions

Администратор может массово изменять статус заявок:

- ✅ Рекомендован к публикации;
- ❌ Не рекомендован;
- Утвердить заявку;
- Отклонить заявку.

## 5. Соответствие требованиям

| # | Требование | Реализация |
|---|------------|-----------|
| 1 | Регистрация новых пользователей | `/register/` |
| 2 | Просмотр конференций | `/`, `/conference/<id>/` |
| 3 | Регистрация авторов | `/conference/<id>/register/` |
| 4 | Редактирование и удаление своих регистраций | `/registration/<id>/update|delete/` |
| 5 | Написание отзывов (дата, текст, рейтинг, автор) | `/conference/<id>/review/` |
| 6 | Указание результатов администратором | Admin actions |
| 7 | Таблица участников | `/participants/` |

## 6. Безопасность

- Все POST-запросы защищены `{% csrf_token %}`.
- Редактирование/удаление заявок ограничено владельцем через `get_queryset`.
- Формы используют встроенную валидацию Django.
- Пароли хэшируются автоматически.
