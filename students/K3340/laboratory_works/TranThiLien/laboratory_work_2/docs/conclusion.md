# Вывод

## Итоги работы

В ходе выполнения лабораторной работы №2 были изучены и практически освоены основные возможности веб-фреймворка **Django 6.1**.

### Практическая работа 2.1

- Освоена установка Django через виртуальное окружение `venv`.
- Создан первый проект `conference_project` и приложение `conference_app`.
- Реализованы модели `Conference`, `Topic`, `Venue`.
- Настроена миграция и регистрация моделей в административной панели.
- Реализовано первое представление (FBV) и маршрут URL.

### Практическая работа 2.2

- Освоены отношения «многие ко многим» через ассоциативную сущность (`through`).
- Реализованы модели `Registration`, `Review`, `ConferenceTopic`.
- Разработаны формы на базе `ModelForm`.
- Освоены Function-Based Views (FBV) и Class-Based Views (CBV).
- Реализованы CRUD-операции для заявок с защитой по владельцу.

### Практическая работа 2.3

- Настроена аутентификация через встроенные модули Django.
- Реализована форма регистрации `UserRegisterForm`.
- Настроены перенаправления после входа/выхода.
- Реализованы Admin actions для массовой обработки заявок.
- Создана сводная таблица участников.

### Вариант 5 — Список научных конференций

Полностью реализован функционал согласно заданию:

## Возможные улучшения

1. **Разделение прав по ролям** — использовать `Group` и `Permission` Django для ролей «Рецензент», «Модератор», «Автор».
2. **Расширение User** — использовать `AbstractUser` для добавления полей (номер паспорта, адрес, национальность).
3. **Загрузка файлов** — принимать тезисы докладов в виде файлов PDF/DOCX.
4. **Email-уведомления** — отправлять автору письмо при изменении статуса заявки.
5. **REST API** — реализовать API на Django REST Framework.
6. **Пагинация** — при большом количестве конференций добавить пагинацию.
7. **Поиск и фильтры** — добавить поиск по названию, фильтр по датам и тематикам.
8. **Тесты** — покрыть модели и представления модульными тестами.
