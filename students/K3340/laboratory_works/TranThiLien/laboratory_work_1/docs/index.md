# Практическое задание 1. Обмен сообщениями по UDP

## Постановка задачи

Необходимо реализовать клиентскую и серверную части приложения с использованием протокола UDP.

Клиент должен отправить серверу сообщение:

```text
Hello, server
```

Сервер должен вывести полученное сообщение и отправить клиенту:

```text
Hello, client
```

Клиент должен вывести полученный ответ.

## Реализация

Для реализации используется библиотека `socket`.

UDP-сокет создаётся следующим образом:

```python
socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
```

Для отправки сообщения используется метод `sendto()`, а для получения сообщения — `recvfrom()`.

Сервер принимает датаграмму, выводит её содержимое и отправляет ответ клиенту.

## Результат выполнения

После запуска сервера:

```text
UDP server запущен на 127.0.0.1:5000
```

После запуска клиента:

```text
Отправлено серверу: Hello, server
Ответ сервера: Hello, client
```

На стороне сервера:

```text
Получено от клиента: Hello, server
```

Таким образом, обмен сообщениями между клиентом и сервером по протоколу UDP успешно реализован.

# Практическое задание 2. Вычисления через TCP

## Вариант

Порядковый номер студента в журнале — **34**.

Количество вариантов — 4.

Номер варианта определяется по формуле:

```text
((34 - 1) mod 4) + 1 = 2
```

Следовательно, используется:

**Вариант 2 — Решение квадратного уравнения.**

## Постановка задачи

Необходимо реализовать клиентскую и серверную части приложения с использованием протокола TCP.

Клиент получает от пользователя коэффициенты квадратного уравнения:

```text
ax² + bx + c = 0
```

и отправляет их серверу.

Сервер вычисляет дискриминант:

```text
D = b² - 4ac
```

и определяет корни уравнения.

## Алгоритм

Если:

```text
D > 0
```

уравнение имеет два действительных корня:

```text
x1 = (-b + √D) / 2a
x2 = (-b - √D) / 2a
```

Если:

```text
D = 0
```

уравнение имеет один действительный корень:

```text
x = -b / 2a
```

Если:

```text
D < 0
```

действительных корней нет.

## Результат выполнения

Для коэффициентов:

```text
a = 1
b = -5
c = 6
```

получаем:

```text
D = 1
x1 = 3
x2 = 2
```

Результат успешно передаётся от сервера клиенту.

# Практическое задание 3. Раздача HTML-страницы по HTTP

## Постановка задачи

Необходимо реализовать сервер, который принимает подключение клиента и отправляет ему HTTP-сообщение с содержимым файла `index.html`.

## Реализация

Для создания серверного TCP-сокета используется:

```python
socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)
```

Сервер выполняет следующие действия:

1. Создаёт TCP-сокет.
2. Привязывает его к адресу и порту.
3. Переходит в режим ожидания подключений.
4. Принимает подключение браузера.
5. Получает HTTP-запрос.
6. Читает файл `index.html`.
7. Формирует HTTP-ответ.
8. Отправляет ответ клиенту.

HTTP-ответ содержит строку статуса:

```text
HTTP/1.1 200 OK
```

заголовок:

```text
Content-Type: text/html; charset=utf-8
```

а также:

```text
Content-Length
```

после чего передаётся тело HTML-документа.

## Результат выполнения

После запуска сервера:

```text
HTTP server запущен: http://127.0.0.1:8080
```

при переходе в браузере по адресу:

```text
http://127.0.0.1:8080
```

отображается содержимое файла `index.html`.

Таким образом, сервер успешно раздаёт HTML-страницу посредством HTTP.

# Практическое задание 4. Многопользовательский чат

## Постановка задачи

Необходимо реализовать многопользовательский чат с использованием TCP и библиотеки `threading`.

Пользователь должен иметь возможность:

* подключиться к серверу;
* указать своё имя;
* отправлять сообщения;
* получать сообщения других пользователей;
* выйти из чата.

## Архитектура

Приложение состоит из двух файлов:

```text
chat_server.py
chat_client.py
```

Один файл клиента может быть запущен несколько раз в разных терминалах.

Сервер хранит подключённых пользователей в структуре:

```python
clients = {}
```

где ключом является TCP-соединение, а значением — имя пользователя.

## Работа с потоками

Для каждого подключённого клиента создаётся отдельный поток:

```python
threading.Thread(
    target=handle_client,
    args=(connection, address),
    daemon=True
)
```

Это позволяет серверу одновременно обслуживать нескольких пользователей.

Для безопасной работы с общей коллекцией подключений используется:

```python
threading.Lock()
```

## Идентификация пользователей

При подключении клиент сначала отправляет серверу имя пользователя.

Например:

```text
Alice
```

Сервер сохраняет имя:

```text
connection -> Alice
```

После этого сообщения пользователя отправляются с его именем:

```text
Alice: Hello everyone!
```

## Выход из чата

Для выхода пользователь вводит:

```text
/exit
```

Сервер удаляет его соединение из списка активных пользователей и сообщает остальным:

```text
[Система] Alice вышел из чата.
```

## Результат выполнения

Были одновременно запущены несколько экземпляров `chat_client.py`.

Например:

```text
Alice
Bob
Charlie
```

Когда Alice отправляет:

```text
Hello!
```

Bob и Charlie получают:

```text
Alice: Hello!
```

Когда Bob выходит:

```text
/exit
```

остальные пользователи получают:

```text
[Система] Bob вышел из чата.
```

Таким образом, реализован многопользовательский чат с использованием TCP и многопоточности.

# Практическое задание 5. Простой веб-сервер GET/POST

## Постановка задачи

Необходимо реализовать простой веб-сервер с использованием библиотеки `socket`.

Сервер должен:

1. Принимать информацию о дисциплине и оценке.
2. Сохранять оценки.
3. Группировать оценки по дисциплинам.
4. Возвращать HTML-страницу со всеми оценками.

## Структура хранения данных

Для хранения используется словарь:

```python
grades = {}
```

Например:

```python
{
    "Математика": [5, 4, 5],
    "Программирование": [5, 5],
    "Физика": [4]
}
```

Такая структура позволяет хранить несколько оценок для одной дисциплины.

## GET-запрос

При запросе:

```text
GET /
```

или:

```text
GET /grades
```

сервер формирует HTML-страницу со всеми оценками.

## POST-запрос

Для добавления новой оценки используется:

```text
POST /grades
```

В теле HTTP-запроса передаются:

```text
subject
grade
```

Например:

```text
subject=Математика&grade=5
```

Сервер извлекает данные из тела запроса, проверяет оценку и добавляет её в соответствующую дисциплину.

## Проверка данных

Сервер проверяет:

* наличие названия дисциплины;
* наличие оценки;
* корректность числового значения;
* диапазон оценки от 1 до 5.

## Результат выполнения

После добавления следующих данных:

```text
Математика — 5
Математика — 4
Программирование — 5
```

получается:

| Дисциплина       | Оценки | Средний балл |
| ---------------- | ------ | -----------: |
| Математика       | 5, 4   |         4.50 |
| Программирование | 5      |         5.00 |

Таким образом, реализован веб-сервер, поддерживающий GET и POST HTTP-запросы и группирующий оценки по дисциплинам.
