# Вариант 2 «Библиотека». Описание

Серверная часть информационной системы для работников библиотеки: учёт книг и их
экземпляров по читальным залам, учёт читателей и выдачи книг, аналитические запросы
и отчёт о работе библиотеки за месяц.

## Стек

| Компонент | Назначение |
| --- | --- |
| Django | ORM, модели, админ-панель |
| Django REST Framework | сериализаторы, generic-представления, REST API |
| Djoser | регистрация, авторизация по токенам, `/auth/users/me/` |
| PostgreSQL | СУБД |
| MkDocs | эта документация |

## Структура проекта

```text
library_project/
├── manage.py
├── .env.example              # параметры подключения к PostgreSQL

    ├── exceptions.py         # ProtectedError -> 409
    ├── admin.py
    └── management/commands/seed_library.py   # демо-данные
```

## Общие правила API

- Базовый адрес API: `http://127.0.0.1:8000/api/`.
- Все запросы, кроме регистрации и получения токена, требуют заголовок
  `Authorization: Token <токен>`. Без него ответ — `401`.
- Данные передаются и возвращаются в формате JSON, даты — в формате `YYYY-MM-DD`.
- Ошибки валидации возвращаются с кодом `400`, отсутствующий объект — `404`,
  попытка удалить объект, на который ссылаются другие записи, — `409`.
