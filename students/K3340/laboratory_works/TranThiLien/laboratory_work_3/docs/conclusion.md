# Вывод

## Итоги работы

### Практическая работа 3.1

- Объекты создавались двумя способами: созданием экземпляра класса с `.save()` и через `.objects.create()`.
- Связь «многие ко многим» с атрибутами заполнялась через ассоциативную сущность `Ownership`.
- Добавлены `related_name` (`cars`, `ownerships`, `licenses`) и построены запросы через связанные таблицы.
- Выполнены запросы с `filter`, `get`, `aggregate`, `annotate`, группировка через `values()`, сортировка `order_by()` и `distinct()`.

### Практическая работа 3.2

- Подключён Django REST Framework, реализованы сериализаторы `Serializer` и `ModelSerializer`.
- Реализованы представления на основе `APIView` и generic-классов.
- Реализованы endpoint-ы для скилов и CRUD-endpoint-ы для воинов с вложенными сериализаторами (профессия, скилы с уровнем освоения).

### Вариант 2 — Библиотека

- Модель данных из 10 моделей (11 таблиц): книги и их экземпляры, залы, читатели, выдачи, история залов.
- CRUD для всех сущностей, GET-запросы с вложенными объектами для связей 1:N и M:N.
- Операции библиотекаря: запись читателя, приём и списание экземпляров, перерегистрация книги в другом зале и читателя в другом зале, исключение не прошедших перерегистрацию.
- Пять аналитических запросов из задания и отчёт о работе библиотеки за месяц по дням и залам.
- Регистрация, авторизация по токенам и вывод текущего пользователя через Djoser.
- СУБД PostgreSQL, документация endpoint-ов средствами MkDocs.

## Полученные навыки

| Навык | Применение |
|-------|------------|
| Запросы ORM | `filter`, `get`, поиск через связанные поля |
| `related_name` | обращение к модели с обратной стороны связи |
| Агрегация и аннотация | `aggregate`, `annotate`, `values`, `Count` с `filter` |
| Сериализация | `Serializer`, `ModelSerializer`, вложенные сериализаторы, `source` |
| Представления DRF | `APIView`, generic-классы, переопределение `perform_destroy`, `get_fields` |
| Транзакции | согласованное изменение текущего состояния и истории (`transaction.atomic`) |
| Djoser | регистрация, токены, `/auth/users/me/` |
| PostgreSQL | подключение Django к СУБД |
| MkDocs | документация API |

## Заключение

Работа позволила на практике освоить построение запросов Django ORM и разработку REST API
на Django REST Framework: от простых представлений на `APIView` до сервиса с вложенными
объектами, бизнес-операциями в транзакциях, аналитикой и авторизацией по токенам.
